# Tem aí? Tem Aqui! — protótipo inicial

Protótipo front-end em HTML, CSS e JavaScript puro para consulta de produtos e reservas em pequenos comércios locais.

## Como executar
1. Extraia a pasta do ZIP.
2. Abra a pasta `tem_ai_tem_aqui` no Visual Studio Code.
3. Abra `index.html` no navegador. Para desenvolvimento, recomendamos a extensão **Live Server**.
4. Os produtos e reservas deste protótipo ficam salvos no `localStorage` do navegador.

## O que já funciona
- Busca por nome de produto, estabelecimento ou categoria.
- Filtro por categoria.
- Exibição de disponibilidade e preço.
- Formulário de reserva com nome, quantidade e código.
- Área demonstrativa do comerciante.
- Cadastro de produto e ajuste de estoque por botões `+` e `−`.
- Visualização das reservas recebidas.
- Layout responsivo para desktop, tablet e celular.

## Importante
Este é um protótipo local para demonstração e validação de interface. Ainda não possui login real, banco de dados compartilhado, geolocalização, envio de mensagens, proteção de dados ou publicação na internet. O `localStorage` é específico do navegador e do dispositivo. A próxima etapa será criar o backend e um banco de dados real para clientes e comerciantes acessarem as mesmas informações.
